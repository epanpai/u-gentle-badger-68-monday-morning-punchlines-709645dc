One joke about Monday mornings, 200 characters at most, judged on laughs.
Entry for the [Monday Morning Punchlines](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty on make.fun.

## The entry

> I asked Monday for a rain check, and it rained deadlines instead.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/mfout python3 main.py
cat /tmp/mfout/entry.txt
```

`main.py` (Python 3, standard library only) validates the joke against the
competition gate — one line, one sentence, 1–200 characters, about Monday —
writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, then reads it back and
verifies the bytes match exactly.
